# BUBUDAISY 🌼

두 사람만의 **비전보드 · 월별 순자산 · 10년 로드맵 · 핵심 목표**를 한 화면에서 보는 PWA.

## 구조

- 정적 파일만 있습니다. `index.html` 에는 **개인 데이터가 한 줄도 없습니다.**
- 최초 방문 시 6자리 비밀번호를 입력하면, 브라우저가 그 비밀번호로
  PBKDF2-SHA256 키를 계산해
  - 검증용 해시로 비밀번호를 확인하고
  - **비공개 방 키**를 만들어 그 방에서만 데이터를 읽고 씁니다.
- 이후 방문은 `localStorage` 에 저장된 인증 상태로 바로 열립니다.
- 데이터는 Firebase Realtime Database 의 `rooms/{방 키}` 에만 존재하며,
  시드는 저장소 밖 스크립트로 한 번만 올렸습니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (UI + 잠금 + 실시간 동기화) |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `sw.js` | 오프라인 캐시 (개인 데이터 통신은 캐시하지 않음) |
| `icon-*.png` | 앱 아이콘 4종 (192/512, maskable) |
| `robots.txt` | 검색 노출 차단 |
