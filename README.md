## 구조

- 정적 파일만 있습니다. `index.html` 에는 **개인 데이터가 한 줄도 없습니다.**
- 최초 방문 시 6자리 비밀번호를 입력하면, 브라우저가 그 비밀번호로
  PBKDF2-SHA256 키를 계산해
  - 검증용 해시로 비밀번호를 확인하고
  - **비공개 방 키**를 만들어 그 방에서만 데이터를 읽고 씁니다.
- 이후 방문은 `localStorage` 에 저장된 인증 상태로 바로 열립니다.
- 데이터는 Firebase Realtime Database 의 `rooms/{방 키}` 에만 존재하며,
  시드는 저장소 밖 스크립트로 한 번만 올렸습니다.
- 화면에서 바로 편집합니다. 각 카드의 `✏️` 또는 카드/항목을 누르면 시트가 열리고,
  저장은 `vision` · `bucket` · `tradeUpStrategies` · `masterPlan` 등 해당 노드에만 PUT/PATCH 되어
  두 사람 폰에 실시간으로 반영됩니다.
- `비전` 탭에서 **편집되는 곳은 두 곳**입니다(2026-11-17 개편).
  - `🗓️ 하나씩 천천히`(예전 이름 `연도별 TOP3 목표`) — 연도 카드마다 오른쪽 `✏️` 버튼(또는 연도 글자)을 누르면 그 연도의
    연도·배지·강조색·3칸을 수정하는 시트가 열립니다. 아래 3칸은 누를 때마다 성공 ✓ 토글. 저장은
    카드 단위(`vision/milestones/{i}`)로만 합니다.
  - `🔄 갈아타기 전략` — 아래 설명 참고.
  목표 카드·전문성 영역·맨 아래 문구는 그대로 보기만 합니다.
  목표 카드 1번 줄은 `순자산 30억원` 을 2·3번 줄과 같은 한 줄 높이로 보여 주고, 오른쪽에
  `현재 순자산` 뱃지(최신 `netWorth` 기록, 없으면 `기록 전`)를 나란히 붙입니다.
  `우리의 다짐` 카드는 화면에서 빠졌습니다(데이터는 `vision/pledge`에 보존).
- 목표 카드의 4번 줄 `세팅력 컨설턴트 / 현재 공부중` 은 방 데이터에 아직 없으면 화면에서만
  붙여 보여 줍니다(`freeGoals()`). 4줄의 오른쪽 `현재` 뱃지는 가장 넓은 뱃지 폭에 맞춰
  `fitGoalBadges()` 가 폭·높이·시작 x좌표를 똑같이 맞춥니다.
- `📚 세팅력 컨설턴트` **바로 아래**, `🗓️ 하나씩 천천히` **위**에 `🎯 8대 핵심 목표` 카드가 있습니다
  (2026-11-18 `목표` 탭에서 옮겨 옴). 체크박스 대신 노란 원형 숫자 `1~8` 로 보여 주는 보기 전용이고,
  `goals` 노드 데이터는 그대로입니다.

## 🔄 갈아타기 전략 카드 (`vision/roadmapFlow`)

`전문성 영역` 아래, `하나씩 천천히` 위에 놓인 흰 카드입니다. 내용은 전부 Firebase
`vision/roadmapFlow` 에서 오고 코드에는 한 글자도 들어 있지 않습니다.

```json
{ "steps":    [ { "badge": "1호기", "emoji": "🏠", "label": "첫 집", "tone": "basic" }, ... 4개 ],
  "waysTitle": "1주택 유지 + 하나 더",
  "ways":     [ { "title": "1주택 + 1분양권", "desc": "새로 짓는 집을 분양받아 복제",
                  "caution": "1년 안에 분양권을 사면 비과세가 어렵습니다" }, ... ],
  "note":     "사업시행인가 · 관리처분인가 · 준공 — 이 단계를 알면 복제 시점이 보입니다" }
```

- **4단계 카드**(`steps`) — 배지·이모지·이름·강조색. `tone: "accent"` 인 단계는 진남색 카드로
  강조됩니다(현재 `찐똘`). 390px 에서는 4칸 가로(강조 칸은 조금 넓게), 359px 이하에서는 2×2.
- **복제 방법 3카드**(`ways`) — 제목·설명·주의 문구. `caution` 을 비우면 노란 주의 박스가 빠집니다.
- **묶음 제목**(`waysTitle`)과 **맨 아래 강조 줄**(`note`) — 비우면 화면에서 빠집니다.
- 수정 방법: 단계 카드나 복제 카드를 **탭**, 또는 카드 오른쪽 위 `✏️` / 맨 아래 남색 줄을 **탭**하면
  바텀 시트가 열립니다. 저장하면 `vision/roadmapFlow` 전체가 PUT 되어 두 폰에 즉시 반영됩니다.
- 값이 아직 없으면 카드에 `＋ 갈아타기 전략 만들기` 버튼이 나오고, 누르면 빈 4단계 틀이 생깁니다.

## 💰 순자산

- `순자산` 탭 맨 위 카드는 **1+3 배치**입니다(2026-11-17 개편).
  ① 카드 폭 전체 크림 박스(`.nwhero`)에 `부부 순자산` 라벨·기준 월 뱃지·큰 금액,
  ② 그 아래 3칸 그리드(`.nw3`, `repeat(3,1fr)`, gap 8px)에 `👩🏻 세은` · `👨🏻 찬규` · `부부 총비용`,
  ③ 맨 아래 `2035년 목표 대비 N%` 진행률 바와 `목표 30억원` — ①·②와 같은 카드 안에 있습니다.
- 3칸 금액은 한 줄로만 보여 주고, 칸보다 길어지면 `fitAmounts()` 가 폰트를 0.5px씩 줄여 맞춥니다
  (`[data-fit]`). 390px·360px 에서 `7억 4,018만원` 이 잘리지 않는 것을 확인했습니다.
- 라벨 표기는 **`부부 총비용`**(띄어쓰기)으로 통일했습니다. 순자산 입력/수정 시트에는
  `부부 순자산` 미리보기 줄 하나만 남기고, `세은 + 찬규` 합계 미리보기 줄은 없앴습니다.

## ✨ 하고 싶은 일 (버킷 · 2026-11-18 `희망` 탭 삭제)

- `희망` 탭은 2026-11-18 하단 탭에서 삭제했습니다. 화면에 들어가는 길은 없지만
  `bucketView()` 코드와 `bucket` 데이터(5개 그룹 · 이모지 · 메모 · 순서)는 방에 그대로 보존합니다.
  아래는 그때까지의 동작 기록입니다.
- 완료 체크 동그라미와 진행률 바는 2026-11-17 에 화면에서 뺐습니다(`items[].done` 데이터는 보존).
  이모지 + 문구 목록만 보이고, 항목을 누르면 `이모지 · 문구 · 메모 · 그룹` 수정 시트가 열립니다.
- `items[].note` 는 항목 문구 바로 아래 작은 회색 글씨로 보입니다.
- **드래그로 순서 바꾸기**(2026-11-18) — 각 줄 왼쪽 `⋮⋮` 핸들을 잡고 위아래로 끌면 같은 그룹 안에서
  순서가 바뀝니다. 터치·마우스 모두 Pointer Events 로 동작하고, 핸들에만 `touch-action:none` 이라
  화면 스크롤은 그대로 됩니다. 손을 떼면 그 그룹 항목의 `order` 를 1..n 으로 다시 매겨
  `bucket/items` 에 PATCH 합니다(다른 필드는 건드리지 않음). 목록이 화면보다 길면 위·아래 끝에서
  화면이 따라 스크롤되고, 그룹 끝을 넘어가면 멈춥니다. 핸들을 건드리지 않고 줄을 누르면 기존처럼 수정 시트가 열립니다.

상단 `📝` 는 **수정 요청 메모장**입니다. 지금 보고 있는 탭 이름이 앞에 붙어 저장되고,

## 방 데이터 노드

| 노드 | 내용 |
| --- | --- |
| `vision` | 목표 카드(연도·나이·순자산 목표·3개 목표)·전문성 영역·다짐·`하나씩 천천히` 연도 카드(`milestones`)·갈아타기 전략(`roadmapFlow`)·맨 아래 문구 |
| `netWorth` | 월별 순자산 (`YYYY-MM`) |
| `goals` / `affirmations` | 8대 핵심 목표(비전 탭에 보기 전용으로 표시) / 4대 확언(탭 삭제 후에도 데이터 보존) |
| `bucket` | 돈 벌면 하고 싶은 일 (5개 그룹 · 이모지 · 메모 · 순서. 탭 삭제 후에도 데이터 보존) |
| `tradeUpStrategies` | 갈아타기 탭의 전략 메모 (제목 · 메모 · 날짜) |
| `strategyMind` | 전략 탭의 `strategy` · `mind` 목록 (`text` · `note` · `order` · `updatedAt`). 화면 아이콘은 그룹 고정(`🍯`/`💛`)이고, 저장된 `emoji` 값은 읽지 않는다 |
| `masterPlan` | 마스터 플랜 (5개 챕터 → 섹션 → 항목, 항목별 `구상` 표시) |
| `roadmap` | (화면에서 제거) 예전 연도별 로드맵 데이터 — 읽지도 쓰지도 않고 보존만 합니다 |

**저장 규칙**: 앱의 모든 저장은 **항목 단위 경로**로 합니다. `strategyMind/strategy` 처럼 목록 노드에
`{"id": {"order": 2}}` 를 PATCH 하면 Firebase Realtime Database 는 그 id 아래 객체를 통째로 갈아 버려
`text` · `note` 같은 다른 필드가 지워집니다. 순서 변경은 반드시 `strategyMind/{목록}/{id}` 에
`order` · `updatedAt` 만 PATCH 합니다.
