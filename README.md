## 🔄 갈아타기 전략 카드 (`vision/roadmapFlow`)

`전문성 영역` 아래, `하나씩 천천히` 위에 놓인 흰 카드입니다. 내용은 전부 Firebase
`vision/roadmapFlow` 에서 오고 코드에는 한 글자도 들어 있지 않습니다.

```json
{ "steps":    [ { "badge": "1호기", "emoji": "🏠", "label": "첫 집", "tone": "basic" }, ... 4개 ],
  "waysTitle": "1주택 유지 + 하나 더",
  "ways":     [ { "title": "1주택 + 1분양권", "desc": "새로 짓는 집을 분양받아 복제",
                  "caution": "1년 안에 분양권을 사면 비과세가 어렵습니다" }, ... ],
  "note":     "사업시행인가 · 관리처분인가 · 준공 — 이 단계를 알면 복제 시점이 보입니다" }
```

- **4단계 카드**(`steps`) — 배지·이모지·이름·강조색. `tone: "accent"` 인 단계는 진남색 카드로
  강조됩니다(현재 `찐똘`). 390px 에서는 4칸 가로(강조 칸은 조금 넓게), 359px 이하에서는 2×2.
- **복제 방법 3카드**(`ways`) — 제목·설명·주의 문구. `caution` 을 비우면 노란 주의 박스가 빠집니다.
- **묶음 제목**(`waysTitle`)과 **맨 아래 강조 줄**(`note`) — 비우면 화면에서 빠집니다.
- 수정 방법: 단계 카드나 복제 카드를 **탭**, 또는 카드 오른쪽 위 `✏️` / 맨 아래 남색 줄을 **탭**하면
  바텀 시트가 열립니다. 저장하면 `vision/roadmapFlow` 전체가 PUT 되어 두 폰에 즉시 반영됩니다.
- 값이 아직 없으면 카드에 `＋ 갈아타기 전략 만들기` 버튼이 나오고, 누르면 빈 4단계 틀이 생깁니다.

- 카드 ② **`2027년 월별 목표`** — `1월`~`12월` 12줄. 왼쪽 체크 = 그 달 완료 토글, 달 줄을 누르면
  `✨ N월 목표` 시트(목표 한 줄 · 메모 여러 줄 · 지우기). 빈 달은 흐린 `목표를 적어 보세요`.
- 데이터: `rooms/{room}/thisYear/2027/goals/{0|1|2}` · `rooms/{room}/thisYear/2027/months/{1..12}`
  = `{ title, note, done, doneAt, updatedAt }`. 칸 하나를 고칠 때 그 칸 경로만 PATCH 하므로
  다른 칸·다른 노드가 지워지지 않는다. 2026년 노드는 손대지 않고 그대로 보존한다.
- 보여 줄 해는 코드 위쪽 상수 `TY_YEAR = '2027'` 하나로 정한다(해가 바뀌면 여기만 고치면 된다).
- 다른 화면(비전·전략·순자산)은 이 탭과 무관하게 그대로다.

## 👀 보기 전용 (찬규 님 기기)

- 기기 프로필(`bubudaisy.me.v1`)이 `chankyu` 인 기기에서는 **네 탭 모두 편집 불가**(2026-11-23 v48).
- 화면: 헤더 아래 `👀 보기 전용` 알약 뱃지. `＋ … 추가` · `＋ 이번 달 순자산 입력` · `✏️` · `🗑` 는
  아예 그려지지 않고(CSS `body.ro`), 체크박스·줄·목표 카드는 눌러도 시트가 열리지 않으며
  `보기 전용이에요 — 세은 님 기기에서 고칠 수 있어요` 토스트만 뜬다. 전략 줄의 스와이프·길게 눌러 끌기도 막힌다.
- 저장: `put`/`patch`/`del` 앞에서 `roBlocked(path)` 가 막는다 — 예외는 접속 표시 `lastSeen/chankyu` 하나뿐이다.
  (`📝 수정 요청 메모`와 `📣 확인 요청`은 방 데이터를 쓰지 않으므로 그대로 쓸 수 있다.)
- 접기(연도 카드·현금흐름 메모)와 순자산 그래프 달 고르기는 보기 동작이라 허용한다.
- 세은 기기나 아직 프로필을 고르지 않은 기기는 예전처럼 모든 편집이 된다.

| `tradeUpStrategies` | 갈아타기 탭의 전략 메모 (제목 · 메모 · 날짜) |
| `strategyMind` | 전략 탭의 `strategy` · `mind` 목록 (`text` · `note` · `order` · `updatedAt`). 화면 아이콘은 그룹 고정(`🍯`/`💛`)이고, 저장된 `emoji` 값은 읽지 않는다. 예전 찬규 탭의 `ck_affirm` · `ck_action` 은 2026-11-23 화면에서 빠졌고 값만 보존한다 |
| `thisYear` | `✨ 올해` 탭 — `2027/goals/{0·1·2}`(2027년 목표 3줄) · `2027/months/{1..12}`(2027년 월별 목표), 각 `title` · `note` · `done` · `doneAt` · `updatedAt`. 2026년 등 지난 연도 노드는 건드리지 않고 보존 |
| `chankyuVision` | (화면에서 제외) 2026-11-23 찬규 탭과 함께 앱에서 빠짐 — 읽지도 쓰지도 않고 값만 보존 (주주가 만들 찬규 님 탭으로 이관용) |
| `masterPlan` | 마스터 플랜 (5개 챕터 → 섹션 → 항목, 항목별 `구상` 표시) |
| `roadmap` | (화면에서 제거) 예전 연도별 로드맵 데이터 — 읽지도 쓰지도 않고 보존만 합니다 |

**저장 규칙**: 앱의 모든 저장은 **항목 단위 경로**로 합니다. `strategyMind/strategy` 처럼 목록 노드에
`{"id": {"order": 2}}` 를 PATCH 하면 Firebase Realtime Database 는 그 id 아래 객체를 통째로 갈아 버려
`text` · `note` 같은 다른 필드가 지워집니다. 순서 변경은 반드시 `strategyMind/{목록}/{id}` 에
`order` · `updatedAt` 만 PATCH 합니다.
