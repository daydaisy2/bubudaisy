# BUBUDAISY 🌼

두 사람만의 **비전보드 · 월별 순자산 · 10년 로드맵 · 핵심 목표 · 하고 싶은 일 · 갈아타기 전략 · 마스터 플랜**을
한 화면에서 보는 PWA. 7개 탭: `비전` `순자산` `로드맵` `목표` `하고싶은일` `갈아타기` `플랜`

## 구조

- 정적 파일만 있습니다. `index.html` 에는 **개인 데이터가 한 줄도 없습니다.**
- 최초 방문 시 6자리 비밀번호를 입력하면, 브라우저가 그 비밀번호로
  PBKDF2-SHA256 키를 계산해
  - 검증용 해시로 비밀번호를 확인하고
  - **비공개 방 키**를 만들어 그 방에서만 데이터를 읽고 씁니다.
- 이후 방문은 `localStorage` 에 저장된 인증 상태로 바로 열립니다.
- 데이터는 Firebase Realtime Database 의 `rooms/{방 키}` 에만 존재하며,
  시드는 저장소 밖 스크립트로 한 번만 올렸습니다.
- 화면에서 바로 편집합니다. 각 카드의 `✏️` 또는 카드/항목을 누르면 시트가 열리고,
  저장은 `vision` · `bucket` · `tradeUpStrategies` · `masterPlan` 등 해당 노드에만 PUT/PATCH 되어
  두 사람 폰에 실시간으로 반영됩니다.
- `비전` 탭은 **보기 전용**입니다(2026-11-17 개편). 편집되는 것은 `🗓️ 연도별 이정표`
  (추가·수정·삭제, 카드마다 핵심 3칸)뿐이고, 목표 카드·전문성 영역·맨 아래 문구는 그대로 보기만 합니다.
  목표 카드 1번 줄은 `순자산 30억원` 오른쪽에 `현재 순자산` 뱃지(최신 `netWorth` 기록, 없으면 `기록 전`)를
  나란히 보여 줍니다. `우리의 다짐` 카드는 화면에서 빠졌습니다(데이터는 `vision/pledge`에 보존).
- 상단 `📝` 는 **수정 요청 메모장**입니다. 지금 보고 있는 탭 이름이 앞에 붙어 저장되고,
  `📋 전체 복사` 로 모아 둔 요청을 한 번에 복사할 수 있습니다. 메모는 `localStorage`
  (`bubudaisy.memos`)에만 저장되어 서버로 나가지 않습니다.

## 방 데이터 노드

| 노드 | 내용 |
| --- | --- |
| `vision` | 목표 카드(연도·나이·순자산 목표·3개 목표)·전문성 영역·다짐·연도별 이정표·맨 아래 문구 |
| `netWorth` | 월별 순자산 (`YYYY-MM`) |
| `roadmap` | 연도별 로드맵 |
| `goals` / `affirmations` | 핵심 목표 / 확언 |
| `bucket` | 돈 벌면 하고 싶은 일 (5개 그룹 · 이모지 · 달성 체크) |
| `tradeUpStrategies` | 갈아타기 전략 (제목 · 메모 · 날짜) |
| `masterPlan` | 마스터 플랜 (5개 챕터 → 섹션 → 항목, 항목별 `구상` 표시) |

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (UI + 잠금 + 실시간 동기화 + 모든 시트) |
| `manifest.webmanifest` | 홈 화면 설치 정보 |
| `sw.js` | 오프라인 캐시 (개인 데이터 통신은 캐시하지 않음) |
| `icon-*.png` | 앱 아이콘 4종 (192/512, maskable) |
| `robots.txt` | 검색 노출 차단 |

## 배포

GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다 (HTTPS 필요 — WebCrypto).
`main` 과 `gh-pages` 두 브랜치를 같은 내용으로 유지합니다.
